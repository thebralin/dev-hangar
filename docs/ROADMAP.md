# Roadmap

## 0.8.0 — готово

- Сворачивание боковой панели в узкую полосу с аватарками (`Ctrl+B`).
- Экран «Все проекты» — сетка карточек: обложка, имя, версия, стек, дата последнего обновления.
  Обложка — своя картинка или автоскриншот (запуск dev → headless Edge/Chrome → остановка), пакетно для всех без картинки.
- Ввод в консоли: строка в stdin запущенного процесса или новая команда в папке проекта, история по `↑`/`↓`.

## 0.9.0 — режим ИИ (идеи, не начато)

1. **Универсальный формат «паспорта» проекта для ИИ** — одна папка в репозитории (условно `.hangar/`):
   описание проекта, документация, статус, задачи, роадмап. Простые markdown/JSON-файлы,
   которые одинаково читают и человек, и ИИ-агент (Claude Code, Cursor, Codex…).
2. **Показ этого в Dev Hangar** — вкладка проекта: описание, статус, задачи, роадмап; редактирование из приложения.
3. **Вызов Claude Code (и других агентов) из Dev Hangar** — запуск агента в папке проекта с подготовленным контекстом.

Открытые вопросы:

- Ядро или плагин? Склоняемся разделить:
  - формат хранения + его отображение — в ядро (нужно большинству);
  - вызов конкретного агента (Claude Code и т. п.) — отдельный плагин, им пользуются не все.
- Формат должен быть заменяемым: если наш вариант не подходит, пользователь подключает свой
  (схема/адаптер через плагин, а не жёстко зашитая структура).
