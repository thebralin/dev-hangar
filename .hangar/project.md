# Dev Hangar

## Описание

Десктоп-приложение на Tauri 2 + Vue 3 (Rust-бэкенд), которое собирает все проекты разработчика в одном окне:
определяет стек, запускает dev/build одной кнопкой, показывает git, файлы, аналитику, граф импортов,
помогает вспомнить, на чём остановился, и расширяется плагинами на JavaScript.

- Фронтенд: `src/` — Vue 3, состояние в `src/lib/store.ts`, Plugin API в `src/plugins/`.
- Бэкенд: `src-tauri/src/` — анализ проектов, git, процессы, файлы, плагины, обложки.
- Паспорт проекта: формат и правки — `src/lib/passport-format.ts`, загрузка и реестр — `src/lib/passport.ts`.
