# Ключевые решения

Записаны по коду, комментариям и документации репозитория.

## Rust отвечает за систему, фронтенд — за логику и UI
Всё, что касается диска, git, процессов и внешних программ, — Tauri-команды в Rust.
Логика плагинов и паспорта живёт на фронтенде; Rust для них только читает и пишет файлы
(`plugins.rs`: «loading and the plugin API live on the frontend»).

## Git вызывается как внешняя программа
Git нужен в PATH (требование README); модули `git.rs`, `gitops.rs`, `checkpoints.rs` запускают его командами.

## Чекпоинты — скрытые коммиты, а не stash или ветки
Снимок рабочей копии (включая неотслеживаемые файлы, с учётом `.gitignore`) пишется через временный индекс
в `refs/devhangar/checkpoints/*`. Ветки, индекс и stash не трогаются. Перед восстановлением создаётся
страховочный чекпоинт, поэтому восстановление тоже можно откатить.

## Плагины — доверенный код, как расширения VS Code
Плагины выполняются в WebView приложения. Разрешения в `plugin.json` ограничивают API `hangar.*`
и показываются пользователю перед включением, но песочницей не являются (`src/plugins/host.ts`).
Установка идёт через временную папку и подмену — неудачное копирование не ломает установленную версию.

## Типы Plugin API — единый источник правды
`src/plugins/hangar.d.ts` проверяется вместе с приложением и копируется в шаблон нового плагина
для автодополнения в редакторе.

## Паспорт проекта — markdown в репозитории
Не база в приложении, а файлы в `.hangar/`: живут в git вместе с кодом, понятны любому ИИ-агенту без интеграций,
полезны и без Dev Hangar (`docs/PASSPORT.md`).

## Ядро и плагины в режиме ИИ
Решено в 0.9.0 (вопрос из прежнего `docs/ROADMAP.md`): формат хранения и его показ — в ядре,
вызов конкретного агента (Claude Code) — отдельный встроенный плагин. Формат заменяемый:
плагин регистрирует свой через `hangar.passport.registerFormat`, плагинные форматы проверяются раньше встроенного.

## Совместимость со старым именем
Приложение раньше называлось Dev Projects Manager: конфиг однократно копируется из
`com.bolat.devprojectsmanager`, старые refs чекпоинтов переносятся под новый префикс при первом чтении.
